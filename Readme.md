Приложение-игра для начинающих читателей по принципу игры "Съедобное-несъедобное". Пользователь должен прочитать слово и определить к какой теме оно относится.

Данные: массив категорий, внутри каждой массивы слов внутри соответствующих тем.

Базовая функциональность приложения:
1. Выводим список категорий, пользователь выбирает необходимую.
2. Выводим по очереди слова из выбранной категории, пользователь при помощи нажатия на кнопку (или перетягивания) определяет, к какой теме относится слово.
3. На счетчике отображается количество правильных и неправильных ответов.
